# TRICO 12U Softball App

**Live Application:** [https://cryptoBrando.github.io/softball-app](https://cryptoBrando.github.io/softball-app)

This is a mobile-friendly web application for the TRICO 12U Softball team. It features:
- **Pregame Itinerary & Live Coach Timer:** A 45-minute live tracking timer with audio whistle notifications.
- **Team Roster:** Manage players.
- **Schedule:** Track upcoming games and events.

*Note: This app is hosted directly via GitHub Pages as a serverless static site. No local package installation or localhost setup is required to access the application.*
